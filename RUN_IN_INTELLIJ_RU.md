# Как открыть и запустить проект в IntelliJ IDEA

1. Распакуй ZIP, чтобы появилась папка `ICT_Assignment1_ECommerce`.
2. Открой **IntelliJ IDEA -> File -> Open** и укажи **папку** `ICT_Assignment1_ECommerce` (не файл ZIP и не вложенную папку `src`).
3. Если появится предупреждение безопасности — нажми **Trust Project**.
4. Если IntelliJ скажет, что отсутствует SDK: **File -> Project Structure -> Project -> SDK -> выбери установленный JDK 17 или новее**. При необходимости нажми Download JDK (но Java должна быть установлена до запуска).
5. Сверху выбери конфигурацию **ECommerce - Main** и нажми зелёный треугольник **Run**.
6. Если конфигурация не отображается: открой `src/ict/ecommerce/Main.java`, нажми зелёный треугольник рядом с `public static void main(String[] args)` и выбери Run Main.main().
7. Если IDE не распознаёт код: нажми правой кнопкой на `src` -> **Mark Directory as -> Sources Root**.

### Быстрая демонстрация

1. В главном меню нажми `2` (Log in), введи e-mail сотрудника и пароль.
2. Нажми `1` (List products), затем `2` (Add book), введи имя, цену, количество и автора.
3. Нажми `5` (List all users), затем `8` (View all orders) — сначала заказов нет.
4. Нажми `0`, заново `2` и войди как покупатель.
5. Нажми `2` (Place order); выбери товар `1`, количество `2`, затем `0` (finish), затем `1` (confirm).
6. Убедись, что появилось **RECEIPT**, сумма 14000.0 KZT, а остаток товара уменьшился с 6 до 4.
7. Нажми `3` (View my orders) и увидишь заказ.

Важно: база данных не предусмотрена; после закрытия программы список заказов снова будет пустой, это нормально для этой учебной версии.

## Как открыть UML

1. Открой https://app.diagrams.net/ (draw.io / diagrams.net).
2. **File -> Open From -> Device** и выбери `diagrams/ECommerce_UML.drawio`.
3. В файле две вкладки: упрощённая схема связей и полная UML-диаграмма с атрибутами и методами.
4. Можно редактировать имена, подписи, расположение классов и экспортировать PNG/PDF.

Перед отправкой преподавателю впиши собственные данные в титульный лист PDF (подготовь персонализированную версию отчёта). Этот шаблон содержит заполнители, потому что имя и ID ты не сообщил.

## Как персонализировать PDF для сдачи

В `docs/Assignment1_Report.pdf` первые три строки титульной таблицы — **редактируемые поля PDF**: Student Full Name, Student ID, Submission Date.

1. Открой PDF в браузере/Adobe Acrobat Reader/Edge, выбери эти поля и введи **свои** данные.
2. Сохрани заполненную копию PDF (лучше «Сохранить как»); проверь, что после повторного открытия данные видны.
3. Переименуй результат в `StudentName-Report.pdf`, где `StudentName` — твоё реальное имя.
4. Отправь **до устной защиты** на `cceken@ku.edu.kz` с темой `ict-assignment1-StudentName`, как требует преподаватель.
5. В IntelliJ должны быть готовы исходники и работающая программа, а `.drawio` — открыт для объяснения диаграммы.
